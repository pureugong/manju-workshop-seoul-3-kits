# 마무리 정리: 오늘 AWS 에 만든 것을 내리고 로그아웃합니다

실습이 끝나면 이 묶음으로 정리해요. 오늘 키트가 만든 것만 골라서 보여 주고, 「지울까요?」에 「네」라고 하면 Claude 가 내립니다. 키트 밖의 것은 건드리지 않아요!

## 쓰는 법

1. 이 묶음(zip)을 풀어서 실습 폴더(예: 문서 폴더 안 `만쥬워크샵`)에 넣습니다. `cleanup` 폴더가 생겨요.
2. Claude 앱의 **Code** 화면에서 새 세션을 열고, 그 `cleanup` 폴더를 고릅니다.
3. 입력창에 한 줄을 보냅니다.

```text
cleanup.md 대로 정리해 줘
```

터미널에는 아무것도 치지 않아도 돼요. 여러분은 「지울까요?」에 답하고, 브라우저에서 Cloudflare 토큰을 지우는 것만 직접 합니다.

## 무엇을 정리하나요

- AWS: 오늘 키트로 만든 파일 보관함, 함수, 작업 순서표(Step Functions)와 시작 신호, 작업 표, 토큰 자리, 로그, 역할, 비용 알림
- Cloudflare 하루용 토큰(직접 지움), Grafana 토큰(만들었다면 직접 지움)
- AWS 로그아웃, GitHub CLI 로그아웃(원하면)

앞으로 AWS 를 계속 쓰실 거라면 사전 준비물의 「부록: AWS 를 안전하게 쓰는 법」 페이지를 봐 주세요.
