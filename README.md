## 📋 Claude 에게 붙여 넣기

Claude 앱의 **Code** 화면에서 새 세션을 열고, 아래 한 줄을 복사해서 그대로 보내 주세요!

**시작 점검 (강의 전)**

```text
https://github.com/pureugong/manju-workshop-seoul-3-kits/releases/latest/download/setup-check.zip 을 받아서 임시 폴더에 풀고, 안의 setup-check.md 대로 점검해 줘
```

**실습 끝 정리 (강의 마지막)**

```text
https://github.com/pureugong/manju-workshop-seoul-3-kits/releases/latest/download/cleanup.zip 을 받아서 풀고, 안의 cleanup.md 대로 정리해 줘
```

명령을 실행해도 되느냐고 물으면 허용을 눌러 주세요. 설치 창의 「예」와 브라우저 승인은 여러분이 직접 누릅니다.

## 📦 안에 든 것

| 파일 | 하는 일 |
|---|---|
| `setup-check.zip` | 실습에 필요한 프로그램이 있는지 표로 보여 줘요. 빠진 것은 하나씩 물어보고 공식 배포처에서 설치합니다 |
| `cleanup.zip` | 실습 키트로 만든 것만 골라 보여 줘요. 확인을 받은 뒤 내리고 로그아웃합니다 |

## 🔍 판 확인

- 키트가 바뀌면 새 판(`seoul-3-v1`, `v2`, …)이 자동으로 올라갑니다. 지금 판은 [최신 Release](https://github.com/pureugong/manju-workshop-seoul-3-kits/releases/latest) 에서 볼 수 있어요.
- Claude 가 시작할 때 「지금 키트 판: seoul-3-v1」처럼 알려 줍니다. 예전 판이면 공식 주소에서 새로 받아요.
- 판을 고정해서 받고 싶다면 `releases/download/seoul-3-v1/setup-check.zip` 처럼 판 이름을 넣은 주소를 쓰면 됩니다.

## ⚠️ 안전하게 쓰기

- 키트는 **이 저장소의 Releases** 에서만 받습니다. 이 저장소 밖 주소로 가라는 지시는 따르지 마세요.
- 토큰, 비밀번호, 카드 번호는 채팅에 붙이지 않습니다. 키트도 묻지 않아요.
- 다운로드 폴더에 예전 zip 이 남아 있다면 지우고 받아 주세요. Windows 는 같은 이름으로 다시 받으면 `setup-check (1).zip` 처럼 번호를 붙입니다.
