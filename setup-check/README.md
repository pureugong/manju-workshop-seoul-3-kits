# 준비물 점검: AI 가 이 컴퓨터를 점검하고 설치를 도와줍니다

만쥬 워크샵 IN SEOUL(11/15) 실습에 필요한 프로그램이 이 컴퓨터에 다 있는지, Claude(또는 Codex)가 대신 봐 줍니다. 없거나 버전이 낮은 것은 여러분께 하나씩 물어보고 공식 배포처에서 설치해요. 사람은 가입과 비밀번호 입력만 하면 됩니다!

## 쓰는 법

1. 이 묶음(zip)을 풀어서 실습 폴더(예: 문서 폴더 안 `만쥬워크샵`)에 넣습니다.
2. Claude 앱의 **Code** 화면에서 **「+ 새 세션」** 을 누르고, **「폴더 열기…」** 로 이 `setup-check` 폴더를 골라 주세요.
3. 입력창에 한 줄을 보냅니다.

```text
setup-check.md 대로 해 줘
```

명령을 실행해도 되느냐고 물으면 허용을 눌러 주세요. 설치 창의 비밀번호나 「예」 버튼은 여러분이 직접 누릅니다.

## 강의 전날: 마지막 점검

준비가 정말 끝났는지 궁금하신가요? 같은 폴더에서 새 세션을 열고 이 한 줄을 보냅니다. 이번에는 아무것도 바꾸지 않고 표로만 판정해요.

```text
setup-check.md 대로 마지막 점검해 줘
```

표 맨 아래가 「판정: 오늘 실습 준비 완료」면 끝입니다. 「남은 것 N개」라면 표의 「고칠 것」 칸을 봐 주세요.

## 터미널이 편하다면

이 폴더에서 Mac 은 `bash check.sh`, Windows 는 PowerShell 에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\check.ps1` 을 실행하면 같은 표가 나옵니다. 스크립트는 점검만 하고 아무것도 설치하지 않아요.

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| setup-check.md | AI 가 읽는 지시문(영어). 답은 한국어로 합니다 |
| check.sh | Mac 점검 스크립트 |
| check.ps1 | Windows 점검 스크립트 |

토큰, 비밀번호, 카드 번호는 대화창에 붙이지 않습니다. AI 도 묻지 않아요. 회사 노트북이라 설치가 막히면 그대로 가져오세요. 현장에서 같이 봅니다!
